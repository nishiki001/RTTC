# RTTC

A casual old-Minecraft tech mod for Minecraft 1.21.1 (NeoForge): forced Programmer Art, lime grass,
Beta-style worlds, and a steam → rails → electricity progression inspired by the Tekkit Classic era.

Work in progress. See `docs/PLAN.md`.

## Development
- JDK 21, IntelliJ IDEA (open `build.gradle` as a project).
- `./gradlew runClient` to launch, `./gradlew build` to build.
